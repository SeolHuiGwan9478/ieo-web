## 4. 서버에 아직 없는 것 (웹 화면을 만들려면 먼저 필요)

"요금·결제 안내"에 적은 정책 가운데 주선사 쪽 서버 상태. **2026-11-14: 30일 기간·자동 갱신·해지를 만들었고 콘솔도 맞췄다.** `PUT /api/brokers/me/plan`에 PRO면 30일 시작(해지해 둔 프로면 해지 취소), BASIC이면 해지(남은 날까지 프로). 응답 `plan.periodEnd`, `plan.cancelAtPeriodEnd`.

| 정책 | 지금 서버 | 필요한 것 |
|---|---|---|
| 30일 단위 결제·자동 갱신 | ✅ 됨 (매일 새벽 4시 10분에 기간이 끝난 프로를 다음 30일로 결제 기록) | - |
| 해지 (남은 날까지 쓰고 멈춤), 해지 취소 | ✅ 됨 (콘솔 플랜 카드 [해지하기]·[해지 취소]) | - |
| 결제 내역 보기 | 없음 | 주선사 결제 기록 조회 API |
| 환불 (7일 안 미사용 전액) | 없음 | 실제 결제를 붙일 때 |

이 화면이 필요하면 서버 담당(이 저장소 밖, `ieo-server`)에게 API를 먼저 요청한다. 기사님 쪽 구현(`DriverSubscription`, `DriverPlanService`)을 본뜨면 된다.

## 5. API (지금 있는 것)

| 요청 | 설명 |
|---|---|
| `GET /api/brokers/me` | `plan: { plan, planLabel, price, features, limits, startedAt }` |
| `PUT /api/brokers/me/plan` `{ "plan": "PRO" }` | 플랜 바꾸기 (대표만). 유료면 DEMO 결제 기록을 남긴다 |

기사님 플랜 API(`/api/plans/me` 등)는 앱 전용이라 콘솔에서 쓰지 않는다.
